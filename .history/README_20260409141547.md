# Feedback App

シンプルで使いやすいフィードバック管理アプリケーションです。ユーザーからのフィードバックを収集・管理できます。

## 特徴

- **簡単なフィードバック投稿**: 名前、カテゴリ、メッセージを入力して送信
- **リアルタイム表示**: 投稿したフィードバックがすぐに画面に反映
- **カテゴリ分類**: バグ報告、機能リクエスト、改善提案など複数のカテゴリに対応
- **フィードバック管理**: フィードバックの詳細表示と削除機能
- **ローカル保存**: ブラウザのLocalStorageを使用してデータを保存
- **レスポンシブデザイン**: スマートフォン、タブレット、デスクトップに対応

## ファイル構成

```
feedback-app/
├── index.html       # メインページ（フィードバック投稿と一覧表示）
├── viewer.html      # フィードバック詳細表示ページ
├── style.css        # スタイルシート
├── script.js        # JavaScriptユーティリティ関数
└── README.md        # このファイル
```

## 使い方

### 1. アプリケーションを開く
1. `index.html` をブラウザで開きます

### 2. フィードバックを投稿する
1. 「フィードバック投稿」セクションで以下を入力:
   - **名前**: 投稿者の名前
   - **カテゴリ**: フィードバックの種類を選択
   - **メッセージ**: フィードバックの内容
2. 「送信」ボタンをクリック

### 3. フィードバックを確認する
- 投稿したフィードバックが「フィードバック一覧」に表示されます
- 「詳細を見る」をクリックして全文を確認
- 「削除」ボタンでフィードバックを削除

## 技術仕様

### 使用技術
- **HTML5**: ページ構造
- **CSS3**: スタイルとレイアウト
- **JavaScript**: インタラクティブ機能
- **LocalStorage API**: データ永続化

### ブラウザ互換性
- Chrome/Edge 90以上
- Firefox 88以上
- Safari 14以上

### データ保存形式
フィードバックはブラウザのLocalStorageにJSON形式で保存されます:

```javascript
{
    id: "タイムスタンプ",
    name: "投稿者名",
    category: "カテゴリ",
    message: "メッセージ",
    timestamp: "ISO 8601形式の日時"
}
```

## 注意事項

- このアプリケーションはLocalStorageを使用するため、ブラウザのキャッシュをクリアするとデータが失われます
- 複数のタブ/ウィンドウ間でのリアルタイム同期には対応していません
- 本番環境では、サーバーサイドでのデータ保存を推奨します
