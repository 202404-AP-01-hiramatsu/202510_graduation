# 匿名フィードバック Webアプリ

シンプルで使いやすい、プレゼンテーションやイベント向けの匿名フィードバック収集アプリケーションです。

## 特徴

- **匿名投稿**: 投稿者の名前を記録しない完全な匿名フィードバック
- **発表者別集計**: 各発表者に対するフィードバックを簡単に確認
- **シンプルなUI**: 直感的で使いやすいインターフェース
- **レスポンシブデザイン**: スマートフォン、タブレット、デスクトップに対応
- **ローカル保存**: ブラウザのLocalStorageを使用してデータを管理

## ファイル構成

```
feedback-app/
├── index.html       # フィードバック投稿ページ
├── viewer.html      # フィードバック閲覧ページ
├── style.css        # スタイルシート
├── script.js        # JavaScript機能
└── README.md        # このファイル
```

## 使い方

### 投稿方法 (index.html)

1. **ブラウザで `index.html` を開く**
2. 発表者名をプルダウンから選択
3. 以下の3つの項目をご記入ください:
   - **良かった点**: 発表で良かった部分や工夫していた点
   - **改善するべき点**: より良くするための提案
   - **備考**: その他のご意見（任意）
4. 「送信する」ボタンをクリック
5. 完了メッセージが表示されます

**注**: 投稿者のお名前は記録されません（完全匿名）

### 閲覧方法 (viewer.html)

1. `viewer.html` をブラウザで開く
2. プルダウンから発表者を選択
3. その発表者に対して送信されたすべてのフィードバックが表示されます
4. 各フィードバックの内容、投稿日時を確認できます

## 項目説明

### 投稿画面

| 項目 | 説明 | 必須 |
|------|------|------|
| 発表者名 | フィードバック対象の発表者 | ○ |
| 良かった点 | 発表の工夫や素晴らしかった点 | ○ |
| 改善するべき点 | さらに良くするための提案やご指摘 | ○ |
| 備考 | その他のご意見やコメント | - |

### 閲覧画面

各フィードバックには以下の情報が表示されます:

- **フィードバック番号**
- **良かった点**
- **改善するべき点**
- **備考**（記入されている場合）
- **投稿日時**

## 技術仕様

### 使用技術
- HTML5
- CSS3（レスポンシブデザイン）
- JavaScript（ES6+）
- LocalStorage API

### データ保存形式

フィードバックはブラウザのLocalStorageにJSON形式で保存されます:

```javascript
{
    id: "1234567890",           // タイムスタンプベースのID
    presenter: "発表者名",        // 発表者名
    positive: "良かった点",       // 良かった点
    improvement: "改善点",        // 改善するべき点
    remarks: "備考内容",          // 備考
    timestamp: "2024-04-09T..."  // ISO 8601形式の投稿日時
}
```

## 使用上の注意

### データ管理
- このアプリケーションはローカルストレージを使用するため、**ブラウザのキャッシュクリア時にデータが失われます**
- 複数のタブ/ウィンドウ間でのリアルタイム同期には対応していません
- **重要なデータは定期的にバックアップ** してください

### セキュリティ
- 本番環境での使用にはサーバーサイドでのデータ保存を強く推奨します
- 個人情報を含めた本格的な運用にはセキュリティ対策が必要です

## セットアップ方法

### 簡単なセットアップ
1. すべてのファイル（.html, .css, .js）を同じディレクトリに配置
2. `index.html` をブラウザで開く
3. すぐに使用できます

### サーバーでの配置
```bash
# 例: Apache/Nginxなどのウェブサーバーに配置
cp index.html viewer.html style.css script.js /var/www/html/feedback-app/
```

その後、ブラウザで`http://localhost/feedback-app/index.html`を開いてください。

## 発表者の管理

発表者リストは `index.html` と `viewer.html` の`<select>`要素で管理されています:

```html
<select id="presenter" name="presenter">
    <option value="">選択してください</option>
    <option value="発表者名1">発表者名1</option>
    <option value="発表者名2">発表者名2</option>
    <!-- ここに追加 -->
</select>
```

発表者を追加する場合は、両方のHTMLファイルの該当箇所を編集してください。

## トラブルシューティング

### 送信したフィードバックが表示されない
- ブラウザのConsoleを確認してエラーがないか確認
- LocalStorageが有効になっているか確認
- プライベート/シークレットモードではLocalStorageが動作しない場合があります

### フィードバックが消えた
- ブラウザのキャッシュがクリアされた可能性があります
- 重要なデータは定期的にバックアップしてください
