# 匿名フィードバック Webアプリ

シンプルで使いやすい、プレゼンテーションやイベント向けの匿名フィードバック収集アプリケーションです。

## 特徴

- **完全な匿名投稿**: 投稿者の名前やメールアドレスを記録しない
- **Supabase連携**: クラウドベースのデータベースで安全にデータを管理
- **発表者別集計**: 各発表者に対するフィードバックを簡単に確認
- **シンプルなUI**: 直感的で使いやすいインターフェース
- **レスポンシブデザイン**: スマートフォン、タブレット、デスクトップに対応
- **フォールバック機能**: Supabaseが利用できない場合はLocalStorageで動作

## セットアップ方法

### 方法1: Supabase使用（推奨）

#### 1. Supabaseプロジェクトの作成

1. [Supabase公式サイト](https://supabase.com)にアクセス
2. GitHubアカウントでサインアップ
3. 「New Project」をクリック
4. 以下の情報を入力:
   - **Project Name**: `feedback-app` など任意の名前
   - **Database Password**: 安全なパスワードを設定
   - **Region**: 日本に近い地域（Asia-Tokyo または Asia-Singapore）を選択
5. 「Create new project」をクリック
6. プロジェクト作成完了を待つ（2-3分程度）

#### 2. テーブルの作成

1. Supabaseダッシュボードの左側メニューから「SQL Editor」をクリック
2. 「New Query」をクリック
3. 以下のSQLコードを貼り付け:

```sql
-- feedbacksテーブルの作成
CREATE TABLE feedbacks (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    presenter TEXT NOT NULL,
    positive TEXT NOT NULL,
    improvement TEXT NOT NULL,
    remarks TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- インデックスの作成（発表者での検索を高速化）
CREATE INDEX idx_feedbacks_presenter ON feedbacks(presenter);
```

4. 「Run」ボタンをクリックしてテーブルを作成

#### 3. Row Level Security (RLS) の設定

セキュリティのため、RLSを有効にします:

1. Supabaseダッシュボードで「Authentication」→「Policies」をクリック
2. 「feedbacks」テーブルを選択
3. **INSERT ポリシー**: 以下を設定
   - Policy name: `Allow anonymous inserts`
   - Target roles: `anon`, `authenticated`
   - Policy expression: `true`
4. **SELECT ポリシー**: 以下を設定
   - Policy name: `Allow anonymous selects`
   - Target roles: `anon`, `authenticated`
   - Policy expression: `true`

または、SQLで以下を実行:

```sql
ALTER TABLE feedbacks ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow anonymous inserts"
    ON feedbacks FOR INSERT
    TO anon, authenticated
    WITH CHECK (true);

CREATE POLICY "Allow anonymous selects"
    ON feedbacks FOR SELECT
    TO anon, authenticated
    USING (true);
```

#### 4. APIキーの取得

1. Supabaseダッシュボードで「Settings」→「API」をクリック
2. 以下の情報をコピー:
   - **Project URL**: `https://xxxxx.supabase.co`
   - **anon public**: `ey...` で始まるキー（これを使用）

#### 5. アプリケーションに設定値を入力

1. **index.html** または **viewer.html** をブラウザで開く
2. ブラウザのConsoleを開く（F12キー）
3. 以下のコマンドを実行:

```javascript
localStorage.setItem('SUPABASE_URL', 'https://xxxxx.supabase.co');
localStorage.setItem('SUPABASE_KEY', 'eyJhbGc...');
```

※ `xxxxx` と `eyJhbGc...` は上記で取得した値に置き換えてください

これで設定完了です！

### 方法2: LocalStorageのみで使用（Supabase不要）

Supabaseなしでも、ブラウザのLocalStorageを使用して動作します:

1. すべてのファイルを同じディレクトリに配置
2. `index.html` をブラウザで開く
3. すぐに使用できます

※ データはブラウザのローカルストレージに保存されるため、キャッシュクリア時に失われます

## 使い方

### 投稿方法 (index.html)

1. **ブラウザで `index.html` を開く**
2. 発表者名をプルダウンから選択
3. 以下の3つの項目をご記入ください:
   - **良かった点**: 発表で良かった部分や工夫していた点
   - **改善するべき点**: より良くするための提案
   - **備考**: その他のご意見（任意）
4. 「送信する」ボタンをクリック
5. 完了メッセージが表示されます

**注**: 投稿者のお名前やメールアドレスは記録されません（完全匿名）

### 閲覧方法 (viewer.html)

1. `viewer.html` をブラウザで開く
2. プルダウンから発表者を選択
3. その発表者に対して送信されたすべてのフィードバックが表示されます
4. 各フィードバックの内容、投稿日時を確認できます

## 項目説明

### 投稿画面

| 項目 | 説明 | 必須 |
|------|------|------|
| 発表者名 | フィードバック対象の発表者 | ○ |
| 良かった点 | 発表の工夫や素晴らしかった点 | ○ |
| 改善するべき点 | さらに良くするための提案やご指摘 | ○ |
| 備考 | その他のご意見やコメント | - |

### 閲覧画面

各フィードバックには以下の情報が表示されます:

- **フィードバック番号**
- **良かった点**
- **改善するべき点**
- **備考**（記入されている場合）
- **投稿日時**: `created_at` から自動的に表示

## セキュリティに関する注意

### 保存されない情報
- ✅ 投稿者の名前
- ✅ メールアドレス
- ✅ IPアドレス
- ✅ User-Agent

### Supabase設定のセキュリティ
- Public API Key（anonキー）は、Row Level Securityと組み合わせて使用
- RLSにより、SQLインジェクション攻撃から保護
- HTTPS通信で暗号化

### LocalStorage使用時の注意
- ブラウザのdevtoolsで設定値を確認されないよう注意
- 本番環境ではサーバーサイドでの認証を推奨

## 発表者の管理

発表者リストは `index.html` と `viewer.html` の`<select>`要素で管理されています:

```html
<select id="presenter" name="presenter">
    <option value="">選択してください</option>
    <option value="発表者名1">発表者名1</option>
    <option value="発表者名2">発表者名2</option>
    <!-- ここに追加 -->
</select>
```

発表者を追加する場合は、両方のHTMLファイルの該当箇所を編集してください。

## トラブルシューティング

### 「Supabase設定が見つかりません」と表示される

**原因**: Supabase URLとAPIキーが設定されていません

**解決方法**:
```javascript
// ブラウザのConsoleで実行
localStorage.setItem('SUPABASE_URL', 'https://xxxxx.supabase.co');
localStorage.setItem('SUPABASE_KEY', 'eyJhbGc...');
location.reload();
```

### データが保存されない

**確認項目**:
1. Supabase URLとAPIキーが正しく設定されているか
2. `feedbacks`テーブルが作成されているか
3. Row Level Security (RLS) のポリシーが正しく設定されているか
4. ブラウザの開発者ツール（F12）のConsoleでエラーが表示されていないか

### 「Authentication failed」エラーが表示される

**原因**: APIキーが無効または期限切れ

**解決方法**:
1. Supabaseダッシュボードで新しいキーを生成
2. 上記の設定手順でキーを再度設定

### LocalStorageのみで使用したい場合

**手順**:
1. Supabase設定をスキップ
2. 通常通りアプリケーションを使用
3. 自動的にLocalStorageで動作します

## データのバックアップ

### Supabaseの場合

Supabaseダッシュボードから:
1. 「Backups」をクリック
2. 自動バックアップは毎日実施（7日間保持）
3. 手動バックアップもできます

### 手動エクスポート

```javascript
// ブラウザのConsoleで実行
const response = await supabaseClient
    .from('feedbacks')
    .select('*');
console.log(JSON.stringify(response.data));
// JSONデータをコピーしてファイルに保存
```
